# CP 设计手册

ADA300PS TMA CP 十一项新增功能的交互式设计说明。

- 思维导图与功能筛选
- 11 项功能的流程、描述符、代码位置与验证边界
- CP 交互实验室：39 个可选数据场景，包含已有路径与 11 项新增方案
- 可调整 concat 数量/方向、slice 范围/步长、六种 permute、gather/scatter 索引
- 逻辑矩阵、元素追踪、256B 物理地址窗口和 128B 字节 lane 联动
- K/Act 与 W/Wgt 块顺序对照，INT4 高低四位打包、SWA 回卷
- local/remote/CP_DLB 路由与读延迟、反压、credit 教学模型
- 参数重排、AP/WP 地址和搬运量演示；映射结果可导出 JSON
- 完整方案及 Word 下载

网站是设计建议与学习资料，不代表新增 RTL 功能已经实现或通过验证。个人笔记与阅读记录仅保存在当前浏览器。

交互实验室入口：`#lab/operations`。每项详情页可以直接跳到对应演示。K 对应 Act，W 对应 Wgt；参数使用 AP/WP。页面中的状态标签来自原基线或设计提案，不是本次 RTL 验收结论。

实验中的教学步骤不等于 RTL 时钟；行号索引不是可直接下发的 ISA 元素偏移；小尺寸模型不自动满足硬件对齐。bulk 只演示连续字节区间语义，其完整指令契约仍需确认。反压模型不包含 AW/B、错误或乱序响应。

## 本地使用

直接用浏览器打开 `index.html`，不需要安装依赖。

## 模型检查

安装 Node.js 后执行 `node tests/lab-model.test.cjs`，覆盖全部场景、独立逐字节的折叠布局枚举、六种三维换轴、索引冲突、非零起点、INT4 打包和 SWA。它验证的是网页坐标模型，不替代 VCS / Lint / STA。

`lab-model.js` 负责纯坐标与操作模型，`lab-ui.js` 负责交互，`lab.css` 负责实验室样式；原手册页面保留在 `app.js`。

## 发布

GitHub Pages 从 `codex/site` 分支根目录发布。网站使用相对资源路径和 hash 路由，无构建步骤。
